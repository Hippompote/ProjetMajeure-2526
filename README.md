# ProjetMajeure-2526
Répertoire du projet de majeure ESE de l'école CPE Lyon

# Auteurs
* Madranges Mathieu
* Salmon Hippolyte
* Sandier Thomas

# Objectif du projet

Prototype de robot d'assistance en gare pour les PMR et personnes âgées pour les guider dans la gare et porter des valises

# Matériel utilisé

* Moteur brushless
* Conception de cartes électroniques
* STM32F3 Discovery
* RPLidar A1
* Webcam
* Raspberry Pi3B

# Logiciels utilisés
* STM32 CubeIDE
* KiCAD
* PiOS Lite

# Structure du répertoire

Le répertoire est constitué de différentes branches sous la forme "Auteurs + Thème". Chaque branche correspond à ce qui a été fait sur une partie du projet (conception PCB, STM32...). Les fichiers readme sont également adaptés pour chaque branche.
